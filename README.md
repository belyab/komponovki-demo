## О проекте

Интерактивная HTML-демонстрация настройки дизайна существующих компоновок вебинара. Пользователь сможет менять доступные параметры камер и выбирать готовые шаблоны в рамках ограничений бизнес-процесса.

## Рабочая область

- Фиксированный дизайн-viewport: **1024 × 768 px**.
- Вся рамка интерфейса должна помещаться в рабочую область без прокрутки.
- Диалоги и всплывающие окна остаются внутри рабочей области.
- Редактор открывается по наведению на плитку компоновки и нажатию кнопки-карандаша в правом нижнем углу плитки.

## Принцип разработки

Сначала собирается статичный каркас основной страницы. Затем поэтапно добавляется интерактивность. Каждый этап показывается на проверку; переход к следующему этапу — только после подтверждения.
